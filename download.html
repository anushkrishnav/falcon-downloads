Before you install

  • Windows 11, 64-bit (Linux: Debian or Ubuntu)
  • 16 GB of memory recommended (12 GB minimum)
  • A processor with AVX2 (most from 2015 onwards)
  • About 3 GB of free disk space for the models, plus your documents
  • An internet connection for the one-time model download

Unsigned beta installer

This beta is not code-signed yet, so Windows SmartScreen shows “Windows protected your PC”. Choose More info then Run anyway, but only for a file you downloaded from this site or the official release page, and check its SHA-256 first.
