# Site icon inventory

The site uses locally served SVG files from [Lucide](https://lucide.dev/), downloaded from its [official repository](https://github.com/lucide-icons/lucide) at commit `a630cec77eac6568b989e87e4947a8bfe45caacd`. No icon CDN or third-party runtime request is needed. The original SVG geometry is unchanged; CSS sizes and tints icons for light and dark surfaces.

The complete [upstream ISC / Feather MIT license notices](lucide/LICENSE) are shipped alongside the SVG files. Footer attribution links to that license. See [source details](lucide/SOURCE.md).

| Icon file | Used for |
| --- | --- |
| `download.svg` | Landing download button |
| `arrow-right.svg` | Installation guide, feature details, combined tour link, and navigation paths in install/privacy/support copy |
| `arrow-up-right.svg` | Clickable feature preview labels |
| `arrow-left-right.svg` | English/Arabic and English/Urdu direction pairs on the landing and installation pages |
| `check.svg` | Landing document benefits and checklist markers throughout the site |
| `play.svg` | Video preview thumbnails |
| `maximize-2.svg` | Expand product preview to fullscreen |
| `menu.svg` | Collapsed mobile navigation on every full page |
| `x.svg` | Close state of mobile navigation |
| `languages.svg` | Translation preview |
| `panels-top-left.svg` | Side-by-side review preview |
| `stamp.svg` | Stamp preview |
| `droplets.svg` | Watermark preview |
| `folders.svg` | Batch translation preview |
| `book-open.svg` | Terminology preview |

The existing Falcon logo and favicon remain brand assets. Native video controls, disclosure triangles, and browser fullscreen controls are drawn by the browser. Screenshot/video content depicts the application and is not replaced with website icons.

The former hand-drawn feature-card icons were removed with the duplicate feature section. Unicode arrow, play and check glyphs were replaced by the SVGs above. `features.html` preserves old links by redirecting to the combined `tour.html` page, retaining the fragment where JavaScript is available.
