# Falcon Pro downloads

Installers and release notes for **Falcon Pro**, a private, fully local document translation tool for English, Arabic and Urdu, built by L24 Technologies.

- **Download:** see [Releases](../../releases). Each release has the installer and a `SHA256SUMS.txt` file.
- **Verify:** compare the SHA-256 of the file you downloaded with the line in `SHA256SUMS.txt`.
- **Install guide and product tour:** the Falcon website.

This repository contains no source code. Beta installers are not yet code-signed, so Windows SmartScreen asks you to confirm (More info, then Run anyway).
