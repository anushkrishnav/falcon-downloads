Install guide

From download to your first translation, step by step. It takes about 15 minutes, most of it the one-time model download.

  1. Check your computer

    Windows 11, 64-bit; 16 GB of memory recommended (12 GB works but is slower); a processor with AVX2; about 3 GB free for the models. No Python, Office or developer tools are needed.

  2. Download the installer

    Open the Download page and choose Download for Windows. Save Falcon_…_x64-setup.exe to your Downloads folder.

  3. Check the file (recommended)

    This confirms the file is exactly the one that was published. Open PowerShell, run the command, and compare the result with the SHA-256 shown next to the download.

    Get-FileHash "$env:USERPROFILE\Downloads\Falcon_1.0.0-beta.3_x64-setup.exe" -Algorithm SHA256
    If the two values differ, do not run the file. Download it again from this site.

  4. Run the installer

    Double-click the file. Because the beta is not signed yet, Windows SmartScreen may say “Windows protected your PC”. Click More info, then Run anyway. Approve the administrator prompt. Setup also installs the Visual C++ and WebView2 components Falcon needs.

  5. Start Falcon

    Open Falcon Pro from the Start menu. A short loading screen appears, then the welcome page. Click Set up Falcon.

  6. Choose a workspace folder

    Pick where Falcon keeps your documents, for example Documents\Falcon. Use a folder on a drive with free space; you can change it later.

  7. Choose protection

    Standard needs no password. Secure Vault encrypts Falcon’s database with a password you choose (at least 8 characters) and gives you a recovery key. Write the recovery key down and keep it safe: it is shown only once.

  8. Install the language models

    On Checking this device, Falcon lists the models: EnglishArabic, EnglishUrdu and scanned-page OCR (about 1.3 GB together). Press Install and wait. Progress shows downloading, verifying and testing. If the connection drops, press Install again and it resumes. When everything is verified the button changes to Continue.

    If a problem is found, Falcon shows a code such as FLC-3003 and what to try. Look it up on the Support page.

  9. Finish setup

    Pick your default direction and finish. Falcon opens your empty workspace.

  10. Translate your first document

    Click Copy files and choose a PDF or Word file. Select it, click Translate, choose the language and Start translation. When it finishes, open it to review. Fix anything highlighted, then Export.

  1. Check your computer

    Debian or Ubuntu 22.04 or newer, 64-bit; 16 GB of memory recommended; AVX2 processor; about 3 GB free for the models.

  2. Download the package

    From the Download page save Falcon_…_amd64.deb.

  3. Check the file

    sha256sum ~/Downloads/Falcon_1.0.0-beta.3_amd64.deb

    Compare it with the SHA-256 on the download page.

  4. Install

    sudo apt install ~/Downloads/Falcon_1.0.0-beta.3_amd64.deb

    Without administrator rights you can unpack it for your own user instead:

    mkdir -p ~/.local/opt/falcon-pro
dpkg-deb -x ~/Downloads/Falcon_1.0.0-beta.3_amd64.deb ~/.local/opt/falcon-pro
~/.local/opt/falcon-pro/usr/bin/falcon

  5. Start Falcon and finish setup

    Open Falcon Pro from your applications menu, then follow steps 5 to 10 of the Windows guide: workspace, protection, Install the models, then translate.

Good to know

Where does Falcon keep my data?

Settings, the database and the downloaded models live in your user profile (%LOCALAPPDATA%\Falcon on Windows, ~/.local/share/Falcon on Linux). Your documents live in the workspace folder you chose.

Can I install the models without internet?

Yes. On a connected machine download the model pack folder, copy it over, and in Settings Models choose Install from folder.

The download stopped or failed

Press Install again; it resumes from where it stopped. If a file fails its check, Falcon says so and asks you to retry. A repeated failure shows a support code, see Support.

How do I update?

Download the newer installer from the Download page and run it over the old one. Your settings, workspace and models are kept.

How do I uninstall?

Windows: Settings Apps Falcon Pro Uninstall. Linux: sudo apt remove falcon. Your documents are never deleted. To remove models and settings too, delete the Falcon data folder above.
