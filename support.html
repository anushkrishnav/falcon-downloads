Need more help?

Send support what it needs

  1. Note the code

    Write down the FLC- code shown with the error and what you were doing.

  2. Open Diagnostics

    In Falcon open Settings Diagnostics. You can read recent problems there and filter by code.

  3. Create the bundle

    Click Create diagnostics bundle. It saves a zip with the app version, system summary, installed model state and recent problems. Your user name and folders are replaced with ~, and it never includes document text or file names.

  4. Send it

    Attach the zip to your message. Review it first if your organisation requires that.

Common questions

Windows says “Windows protected your PC”

The beta installer is not code-signed yet. Check the SHA-256 on the install guide, then choose More info Run anyway.

The Arabic or Urdu translation reads oddly

Machine translation is a first draft. Review it in the editor. Add approved terms under Terminology so they are used every time, and keep the original document for reference.

Numbers or names changed in the translation

Falcon flags number mismatches in the review panel. Click the warning to jump to the line and correct it. Always check figures, dates and names against the original.

A scanned page was not translated

Scanned pages need the OCR model (installed at setup). Scanned Urdu is not yet fully validated; review it closely.

I forgot my vault password

Use the recovery key you saved at setup. Falcon cannot show it again.

Diagnostics

Where to find your support code

Open Settings Diagnostics. Problems are listed with their FLC- code, and the buttons at the top copy a short report or create a support bundle with your home folder and file names removed.
