Falcon Email Translator

Translate Gmail and Outlook web messages with Falcon’s local model, and save a whole thread into your workspace as plain text or PDF. Nothing leaves your computer.

Install guideManual download
What it does

Read foreign-language email, keep the thread

An extension for Chrome, Chromium and Edge adds Falcon buttons to Gmail and Outlook on the web. Falcon, running on the same computer, does the translating.

  • Translate a message. Arabic or Urdu mail is translated into English, English mail into Arabic or Urdu (your choice). Right-to-left text displays right-to-left, and you can copy the translation or hide it again.
  • Translate a thread in one click, message by message.
  • Save thread to Falcon writes the open messages into the Email threads folder of your workspace as plain text (.txt) or a PDF, whichever you choose.
  • Nothing runs until you press a button.

Arabic and Urdu translate to and from English only, never directly to each other. Machine translation must be reviewed before it is relied on.

Privacy

Everything stays on this computer

No network

The extension makes no network requests, has no analytics and loads no remote code. Its pages are locked down by a strict content security policy.

Native messaging only

The browser talks to a small local program (the bridge), which talks to Falcon over a private per-user connection. No port is opened for the web.

You approve each browser

Falcon asks before an extension can connect, and only the extension ID it expects is accepted. Paired extensions are listed in Settings → Browser extension, and you can revoke any of them or switch the feature off.

Only what you press

Text is sent to Falcon only when you press Translate or Save. The extension cannot read your files or library, and it never logs email text. Requests show in Falcon’s Jobs page as counts and timing only.

Requirements

What you need

  • A Falcon Pro build that has Settings → Browser extension (it arrives after 1.0.0-beta.4; the beta.4 installer does not include it), with the language models set up, and running while you translate
  • Windows 11 (64-bit) or Linux (Debian or Ubuntu), with Chrome, Chromium or Edge
  • Gmail or Outlook on the web (mail.google.com, outlook.office.com, outlook.live.com, outlook.office365.com)
  • An open workspace folder in Falcon, if you want to save threads
Install guide

Install from inside Falcon

About five minutes, no terminal. The same steps work on Windows and Linux: Falcon ships the helper program and the extension folder, and sets the connection up for you. Edge uses edge://extensions.

  1. Open Falcon and turn on the connector

    Open Falcon Pro (beta), go to Settings → Browser extension and switch on Turn on the connector. This page is a four-step checklist; each step shows a tick when it is done. Open a workspace folder as well: saved threads go there.

  2. Press Install connector

    Falcon copies its small helper program (the bridge) to your own user folder and tells Chrome, Chromium and Edge about it. No terminal, no administrator rights, and it works the same on Windows and Linux. Afterwards the step shows where it was installed and which browsers are ready. Repair and Remove are in the same place. If your browser was open, restart it.

  3. Add the extension to your browser

    In Chrome, Chromium or Edge open chrome://extensions (Edge: edge://extensions) and turn on Developer mode. Press Load unpacked and choose the folder that Falcon shows in step 3. Use Copy folder path and paste it into the folder dialog. This is a one-time step until the extension is on a browser store.

  4. Check the extension ID

    The extension’s card should show fedkaibcglbjaadcnofhjpdododggdgl, the same ID as Falcon’s step 3 (it has a Copy ID button). Falcon only accepts that ID.

  5. Pair the browser

    Click the Falcon icon in the browser toolbar. The popup says Not paired yet: press Pair with Falcon. Falcon comes to the front with a prompt. Check the name and press Allow. Allow stays greyed for a moment so a stray click cannot approve a connection. Decide later closes the prompt; the request then waits in step 4 of the Settings page and lapses by itself after two minutes, when you can press Pair again.

  6. Open Gmail or Outlook on the web

    Open a message. A Translate button appears above each message body and a small Falcon card appears at the bottom right. The popup now says Connected to Falcon.

Manual install and downloads

Only if the in-app installer is not available

Normally you do not need these files. Use them if Falcon says it cannot find its helper file or the extension folder, or if you want to set the connection up by hand.

Unsigned beta: SmartScreen

The beta bridge programs are not code-signed, so Windows SmartScreen may show “Windows protected your PC” for falcon-bridge.exe or the .bat file. Choose More info, then Run anyway, but only for files from this site or the official release page, and only after checking the SHA-256 values.

Check the files

Windows PowerShell:

Get-FileHash "$env:USERPROFILE\Downloads\falcon-email-extension-0.2.0.zip" -Algorithm SHA256

Linux:

sha256sum -c SHA256SUMS.txt --ignore-missing

Manual install steps

  1. Download the files

    Use the download card above: the extension zip, the bridge for your system (Windows zip or Linux tar.gz) and SHA256SUMS.txt. Check the SHA-256 values.

  2. Unzip them into permanent folders

    For example C:\Users\<you>\FalconBridge and a folder for the extension. Do not run anything from inside a zip, and do not move or delete these folders afterwards: the browser keeps using them.

  3. Register the bridge

    Windows: double-click install-bridge.bat, paste the extension ID (or press Enter for the default) and wait for Done. It needs no administrator rights. If SmartScreen says “Windows protected your PC”, choose More info, then Run anyway: the manual installer is not code-signed.

    Linux: unpack the tar.gz, then run

    EXTENSION_ID=fedkaibcglbjaadcnofhjpdododggdgl ./install.sh install ./falcon-bridge

    (./install.sh uninstall removes it again.)

  4. Load the extension, restart the browser, pair

    Follow steps 3 to 6 above, choosing the unzipped extension folder in Load unpacked. Restart the browser completely first.

Troubleshooting

If something does not work

The message says “Open Falcon, then try again”

Falcon is not running, or the connector is switched off. Start Falcon, make sure step 1 in Settings → Browser extension is on, and press Translate again. The popup says Falcon is not running in the same situation.

“This browser is not connected to Falcon yet” (not paired)

Press Pair with Falcon (in the message or in the popup), then press Allow in Falcon. If you chose Decide later or the request lapsed, press Pair again. If you pressed Deny, pair again and Allow.

“Too many requests” (rate limited)

Falcon limits how fast one extension can send work. Wait a moment and try again, and translate threads one at a time.

The popup says “Falcon connector not installed”

The browser cannot find the helper program. Open Falcon, go to Settings → Browser extension and press Install connector (or Repair), then restart the browser completely. If you used the manual install and moved the bridge folder, run its installer again.

The browser is not allowed to use the bridge

The bridge accepts only the extension ID Falcon expects, fedkaibcglbjaadcnofhjpdododggdgl. Compare it with the ID on the extension’s card. If you loaded a different build of the extension, the ID differs: use the extension folder Falcon shows in step 3.

Windows SmartScreen blocks something

Only the manual installer is affected. Click More info, then Run anyway, after checking the SHA-256 values against the download card. The in-app installer needs no separate file.

The buttons do not appear on a message

Gmail and Outlook change their page layout without notice, and the extension finds messages by matching that layout. Only expanded messages have text on the page. Reload the page. If buttons are still missing, the layout may have changed since this beta; see the limitations below.

How do I remove it?
  1. In Falcon, Settings → Browser extension: Revoke the pairing under Paired extensions, and press Remove in step 2 to take the connector out. Switch the connector off if you like.
  2. Remove the extension at chrome://extensions.
  3. Manual install only: run uninstall-bridge.bat (Windows) or ./install.sh uninstall (Linux), then delete the folders.

Saved threads in Email threads are your files and are never deleted.

Known limitations

Honest notes about the beta

  • Beta, unsigned. The bridge programs are not code-signed, and the extension is loaded unpacked (Developer mode), not from a browser store. Your browser may remind you about developer-mode extensions.
  • Windows connection not widely tested. The named-pipe connection between the bridge and Falcon on Windows has had little testing outside the developers’ machines. The Linux build is less tested on real mail than on test pages.
  • Not tested against live Gmail or Outlook. The extension was developed against hand-written approximations of their pages. Their layouts change without notice, so buttons can disappear or misbehave after a redesign. Failure is graceful: a message without a recognised body simply gets no button.
  • Plain output. Saved threads are plain text or a text-only PDF: no attachments, images or original formatting. Quoted replies and signatures are removed only when the page marks them clearly; otherwise nothing is dropped and the card says so.
  • Open messages only. Collapsed messages are not translated or saved.
  • Chrome, Chromium and Edge only. Firefox is not set up by the installer.
